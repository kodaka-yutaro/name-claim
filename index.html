Can you name something nobody has?

Propose a name. If no one on this site has ever proposed it, it’s yours.

Names are compared exactly as typed: “Alice” and “alice” are different names. Each device counts once per name.

What is Name It First?

Name It First is a simple word game played by everyone who visits this site. Type any name, a pet name, a band name, a made-up word, a name for a star, and press the button. If nobody here has ever proposed exactly that name, you are the first, and the name is recorded as yours. If someone already proposed it, you will see how many times it has been proposed so far.

How are names counted?

Names are compared exactly as they are typed, so capital letters, spelling and character width all matter. Each device is counted once per name: trying the same name again from the same browser does not raise its count. No sign-up is needed.
